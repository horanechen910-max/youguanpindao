# 03 · 脚本模板

## 六段式叙事骨架（每期复用）

这是频道最重要的"生产模具"。每期都套同一套骨架，只换内容。

| 段落 | 时长占比 | 作用 | 写作要点 |
|---|---|---|---|
| 1. 冷钩子 | 0–30 秒 | 抛悬念 | 一个反差结局 / 震撼数字，先果后因 |
| 2. 高光时刻 | 15% | 建立落差 | 它曾经多牛，越牛后面越惨 |
| 3. 第一道裂缝 | 20% | 埋伏笔 | 问题最早从哪冒头，常被忽视的信号 |
| 4. 崩盘连锁 | 30% | 主体叙事 | 决策失误如何滚雪球，节奏要快 |
| 5. 死因鉴定 | 25% | 原创价值 | 提炼 2–3 条核心教训（核心差异点） |
| 6. 留白 + 互动 | 10% | 促评论 | 一句反问 + 下期预告 |

> **重中之重**：第 1 段"钩子"和第 5 段"死因鉴定"决定成败。AI 生成初稿后，这两段必须人工重写。

## 标题公式

反差 + 数字 + 悬念，任选其一套用：

- `曾经[巅峰数据]，[品牌]是怎么[崩盘动词]的？`
  - 例：曾经估值 2000 亿，乐视是怎么一夜归零的？
- `[品牌]之死：[一个扎心的数字 / 事实]`
  - 例：ofo 之死：1500 万人的押金去哪了？
- `发明了 X，却死于 X：[品牌]的悲剧`
  - 例：发明了数码相机，柯达却死于数码相机
- `从[巅峰]到[谷底]，[品牌]只花了[时间]`
  - 例：从市占率第一到卖身，诺基亚只用了三年

**标题原则**：22 字以内、前 10 字必须有信息量（移动端会被截断）。

## 缩略图公式

移动端 3 秒可读，元素不超过 3 个：

1. 品牌 Logo（做**褪色 / 裂纹 / 打叉**处理）
2. 一个核心大数字（如"归零""−2000 亿""1500 万押金"）
3. 红色下跌箭头或裂痕特效 + 高对比背景

**避坑**：不要堆文字、不要小图标、不要低对比配色。做一个模板，后续只换 Logo 和数字。
