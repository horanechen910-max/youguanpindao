# 09 · 素材与版权清单（第一季 EP01–EP12）

> 用途：给你或剪辑外包"照表备料"。逐期列出需要的画面、图表、动画、人物/Logo 注意事项与音乐，并按**版权合规风险**分级。
> 配套：各期内容见对应脚本与 `EPxx-<名称>-镜头清单.md`；数字与事实出处见各脚本"资料来源"。

---

## 一、合规总则（备料前必读）

| 素材类型 | 风险 | 处理原则 |
|---|---|---|
| 自制数据图表 / 动态动画 | 🟢 无 | **首选**。所有关键数字尽量做成自制图表，统一风格、最安全。 |
| 免版税 / 可商用 BGM、音效 | 🟢 低 | 用正规曲库，**保存授权凭证**；不用未授权流行歌。 |
| AI 生成示意图 | 🟡 低–中 | 用于抽象概念可视化；**不影射真实在世人物长相**，不伪造"新闻画面"。 |
| 新闻截图 / 存档画面 | 🟡 中 | 仅用**公开报道**，加来源水印；单一来源连续引用时长要短，配原创解说与分析（构成评论/转化性使用）。 |
| 商标 / 公司 Logo | 🟡 中 | 用于评论、报道、识别性用途；做褪色/裂纹/打叉处理，不暗示对方背书。 |
| 真人肖像 / 人物画面 | 🔴 高 | 只用**公开活动/新闻画面或剪影**；不拼接成误导性情节；不用争议性标签；涉司法只用已公开信息。 |
| 背景流行音乐 / 影视片段 | 🔴 高 | **避免**。版权风险高，易被下架/索赔。 |

> 黄金法则：**能自制就自制；必须引用就标来源、控时长、加原创分析**；人物与司法表述以公开信息为准，措辞客观。每期片尾与简介固定标注"本视频基于公开信息整理，不构成任何投资建议"。

## 五、给外包的备料 SOP

1. 先交付**通用复用资产**（片头/片尾/版式/字幕/图表模板/BGM 歌单），一次到位。
2. 按"逐期素材清单"建每期素材文件夹：`assets/EPxx/{news, charts, ai, broll, audio}`。
3. **档案/新闻素材**：截图保存原始链接到 `EPxx/news/_sources.txt`，与脚本"资料来源"对应。
4. **自制图表/动画**：用统一模板，导出带工程文件，便于后续复用。
5. 交付前过一遍下方**每期备料检查清单**。

### 每期备料检查清单（模板）
- [ ] 三大重点动画素材齐备
- [ ] 所有关键数字均有自制图表，且与脚本/来源一致
- [ ] 新闻/存档画面均带来源水印，单一来源时长可控
- [ ] 人物画面仅用公开素材；Logo 已做处理；无误导性拼接
- [ ] BGM/音效均为可商用且已存授权
- [ ] 片头/片尾/字幕样式统一
- [ ] 片尾+简介含"不构成投资建议"声明
- [ ] ⚠️ 风险项已复核（如 EP11"84 亿"、EP09 亏损口径、各期司法/人物表述）

## 六、风险分级速查（汇总）

| 风险 | 涉及素材 | 出现的高关注期 |
|---|---|---|
| 🔴 高 | 在世人物画面 / 司法表述 | EP01 贾跃亭、EP02 戴威、EP04 刘剑等、EP05 罗永浩、EP07 冯鑫、EP08 Neumann、EP11 毕福康/戴雷 |
| 🟡 中 | 新闻截图、公司 Logo、AI 示意图 | 全季 |
| 🟢 低/无 | 自制图表/动画、可商用音乐 | 全季（优先使用） |

> 总体策略：**视觉以自制图表与动画为主干，新闻/存档素材为佐证，人物与司法表述严格基于公开信息并客观克制**——这套组合既安全，又能形成"败局档案馆"统一的纪录片质感。
