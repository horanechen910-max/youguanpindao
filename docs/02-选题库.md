# 02 · 选题库

## 选题标准（三个必须）

1. **有充分公开报道**：新闻、财报、判决书、招股书可查，规避法律风险，也保证有料可讲。
2. **有认知度或话题性**：观众一听名字就有情绪，利于点击与评论。
3. **有清晰的"死因"**：能提炼出 2–3 条可迁移的商业教训，否则只是流水账。

> 冷启动策略：早期**偏重中文案例**（搜索量大、情绪共鸣强、评论区活跃，利于算法冷启动），中间穿插全球经典款（素材多、长青）。

## 系列化思路（提高粘性）

- **行业专题月**：如"造车新势力败局月""共享经济翻车月"。
- **国别对照**：同一行业中外对比（如中美共享单车）。
- **人物专题**：聚焦争议创始人的决策复盘。
