# 01 · 频道定位

## 核心定位

用"法医解剖"的视角，复盘中外公司 / 品牌 / 产品的兴衰。不煽情、不喊口号，每期给出**可迁移的商业认知增量**。

## 差异化锚点

市面上"成功学 / 创业鸡汤"过剩，"失败复盘 + 客观分析"稀缺。

我们卖的不是猎奇，是 **"看完能学到东西"的确定性** —— 这决定了高完播率与高粘性，也是与搬运号的根本区别。

## 目标受众

- 25–40 岁，对商业、职场、投资感兴趣的人群。
- 这群人撑起两个关键价值：**高 CPM**（财经商业类广告单价高）+ **后期付费意愿强**。

## 频道名

最终选定：**「败局档案馆」**

候选与取舍：

| 候选名 | 调性 | 取舍 |
|---|---|---|
| 败局档案馆 ✅ | 系列感、卷宗感、可无限延展 | **首选**，便于后续做付费会员"密档" |
| 商业尸检报告 | 钩子强、稍重口 | 适合更年轻受众 |
| 凉透了 | 轻松、口语化 | 适合做切片 / Shorts 子账号 |
| 商业沉浮录 | 稳重、纪录片调性 | 偏严肃，钩子稍弱 |

## 视觉调性

- 整体：冷色调、档案 / 卷宗质感，低饱和 + 关键处红色高亮。
- 字体：黑体类，厚重、克制。
- 统一片头（3–5 秒）+ 统一片尾引导（订阅 + 下期预告）。

## 时长策略

- **起步期（前 15–20 期）**：8–12 分钟。先跑通节奏、钩子、完播率。
- **稳定期**：拉到 15–20 分钟。财经题材长视频广告位更多，营收更高。
- **引流**：把长视频的钩子片段切成 60 秒以内竖屏 Shorts。

## 内容红线

- 只做有充分公开报道支撑的案例。
- 客观、克制，避免定性式人身攻击。
- 每期必须有原创"死因鉴定"分析段，不做纯叙事搬运。
