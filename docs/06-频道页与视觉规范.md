- **尺寸**：800 × 800 px（实际显示为圆形，约 98 × 98 px）
- **格式**：PNG（透明背景更稳妥），文件 < 4MB
- **设计**：

## 七、缩略图模板规范（最重要）

### 基础规格
- **尺寸**：1280 × 720 px（16:9），最小宽度 640
- **格式**：JPG / PNG，文件 < 2MB
- **可读性测试**：缩到手机上一个拇指大小时，主数字仍清晰可读

### 固定三元素模板（每期只换内容）
1. **品牌符号**：公司 Logo 或产品剪影，做**褪色 / 裂纹 / 落锁 / 打叉**处理（暗示"完了"）
2. **一个核心大数字**：占画面最大视觉权重
   - 例：`1500亿→0`、`1000万+ 退押金`、`市占率 第一→消失`
3. **红色下跌信号**：下跌箭头 / 裂痕 / 红色描边

### 版式与配色
- **布局**：左 1/3 放品牌符号，右 2/3 放大数字（或上下分区）
- **主色板**：
  - 背景：深灰 / 近黑 `#1A1A1A`
  - 主文字：白 `#FFFFFF`
  - 高亮 / 下跌：红 `#E23B3B`
  - 辅助高亮：暖黄 `#F2C94C`
- **字体**：思源黑体 / 阿里巴巴普惠体等厚重黑体，**加粗 + 描边/阴影**保证对比
- **文字量**：缩略图上 ≤ 6 个字 + 1 组数字，不堆字

### 避坑清单
- [ ] 不做与内容不符的标题党数字（封面数字必须在视频里出现并有来源）
- [ ] 不用低对比配色（红字配深红底等）
- [ ] 不堆超过 3 个视觉元素
- [ ] 同一系列保持版式统一，形成频道辨识度
