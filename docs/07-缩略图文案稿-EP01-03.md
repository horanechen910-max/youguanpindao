# 07 · 缩略图文案稿（EP01–EP03）

> 依据 `06-频道页与视觉规范.md` 的"固定三元素模板"出稿，每期给 2–3 个 A/B 版本。
> 规格：**1280 × 720（16:9）**，文件 < 2MB，手机拇指大小仍可读。
> 三元素 = ①品牌符号（褪色/裂纹/落锁/打叉）②一个核心大数字 ③红色下跌信号。
> 主色板：背景近黑 `#1A1A1A`｜主文字白 `#FFFFFF`｜下跌红 `#E23B3B`｜辅助黄 `#F2C94C`。
> 文字量：封面字 ≤ 6 字 + 1 组数字。下方 ASCII 仅为版式示意，非等比。

## EP01 · 乐视（3 版）

### A 版 ·「归零」数字冲击（主推）
- **钩子角度**：最大反差数字，点击率通常最高
- **品牌符号**：乐视 Logo，裂纹处理，置于左侧
- **主数字**：`1500亿 → 0`（"0"用红色超大号）
- **副文案**：`千亿帝国 归零`（白字，左下）
- **下跌信号**：贯穿画面的红色下跌箭头
- **配色**：黑底 + 白字 + 红"0"/红箭头

```
┌─────────────────────────────────────┐
│  [乐视Logo·裂]        1500亿         │
│                          ↘           │
│                       → 0            │  ← "0" 占最大视觉权重(红)
│  千亿帝国 归零                        │
└─────────────────────────────────────┘
```

### B 版 ·「生态化反」概念钩子
- **钩子角度**：用那个"杀死公司的词"制造好奇
- **品牌符号**：乐视 Logo，缩小置右上
- **主文案**：`"生态化反"`（黄色大字，加引号）
- **副文案**：`一个词，搞垮千亿公司`（白字）
- **下跌信号**：四个字下方裂痕特效

```
┌─────────────────────────────────────┐
│                        [乐视Logo·裂] │
│     "生态化反"                        │  ← 黄色超大字
│     ╲╱╲╱ 裂痕 ╲╱╲╱                   │
│  一个词，搞垮千亿公司                  │
└─────────────────────────────────────┘
```

### C 版 ·「下周回国」话题钩子
- **钩子角度**：全网梗，认知度高、易传播
- **品牌符号**：创始人剪影（仅用公开报道画面/剪影，避免肖像争议）+ 乐视 Logo 角标
- **主文案**：`"下周回国"`（白字大号）
- **副文案**：`他欠了多少，走了多远`（黄字小号）
- **下跌信号**：红色问号 / 红框

```
┌─────────────────────────────────────┐
│  [人物剪影]      "下周回国"           │
│                  ?  (红)             │
│              他欠了多少，走了多远      │
│  [乐视Logo角标]                       │

```

## A/B 测试与统一规范

- **每期先做"主推版"（标 ★ 的 A 版）上线**，2–3 天后若点击率（CTR）偏低，再换 B/C 版。
- **同一系列保持版式统一**：Logo 位、数字位、红色信号位固定，形成频道辨识度。
- **真实性红线**：封面数字必须在视频里出现且有来源（见各 EP 脚本"资料来源"），不做标题党。
  - 乐视："较高点蒸发 99.6%"为已核查口径；若用"1500亿→0"，需在视频内说明是"市值高点→退市归零"的示意，避免误解为精确市值。
  - ofo："1000万+ / 99元 / 199元"见 `EP02-ofo.md`。
  - 诺基亚："50.8%→3.1% / 72亿美元"见 `EP03-诺基亚.md`，封面取整为"50%→3%"。
- **母版交付**：在设计工具里建 1 个 1280×720 母版，分三个图层组（品牌位 / 数字位 / 红色信号位），后续每期只替换内容。
