# 04 · 生产 SOP（单期标准流程）

## 流程总览

```
选题确认 → 资料聚合 → 事实核查 → 脚本初稿 → 人工重写钩子&死因
        → AI 配音 → 画面素材 → 剪辑+字幕 → 缩略图 → 发布优化 → Shorts 切片
```

单期目标工时（熟练后）：1–1.5 天 / 期。

## 分步操作

### 1. 资料聚合（AI 辅助）
- 用 AI 汇总公开报道、财报、时间线、关键人物言论。
- 产出一份"事实清单 + 时间线"草稿。

### 2. 事实核查（人工，不可省）
- 逐条核对关键数字、日期、事件因果。
- 标注每个关键事实的来源链接，存入脚本备查。
- **凡是无法找到公开来源的说法，一律删除或改为"据公开报道"。**

### 3. 脚本初稿（AI 辅助）
- 套用 `03-脚本模板` 的六段式骨架生成初稿。

### 4. 人工重写（核心增值）
- 重写**冷钩子**：先抛震撼结局 / 数字。
- 重写**死因鉴定**：这是原创分析，决定专业度与差异化。

### 5. AI 配音
- 使用情感自然的中文 TTS。
- 语速适中、断句清晰；关键句留停顿。
- 统一一个声音作为频道"主播"人设。

### 6. 画面素材
- 新闻截图、财报图表、合规存档画面。
- **数据图表尽量自制**（更安全、更专业、可统一风格）。
- AI 生成示意图用于抽象概念可视化。
- 关键转折用动态数据动画强化。

### 7. 剪辑 + 字幕
- 卡点节奏，钩子段不超过 30 秒。
- **全程中文字幕**（中文区刚需，也利于完播）。
- 统一片头片尾。

### 8. 缩略图
- 套用 `03-脚本模板` 的缩略图公式，模板化批量出图。

### 9. 发布优化
- 标题：套用标题公式，22 字内。
- 描述 + 章节时间戳 + 标签（见模板）。
- 加"本视频基于公开信息，不构成投资建议"声明。

### 10. Shorts 切片引流
- 把长视频最强钩子片段切成 60 秒竖屏。
- 结尾引导"完整复盘看主页"。

## 工具链建议（按环节）

| 环节 | 工具类型 | 说明 |
|---|---|---|
| 资料聚合 | LLM | 汇总 + 时间线整理 |
| 脚本 | LLM | 套模板生成初稿 |
| 配音 | 中文 TTS | 选情感自然的音色 |
| 图表 | 表格 / 设计工具 | 统一可视化风格 |
| 剪辑 | 视频剪辑软件 | 支持自动字幕更省时 |
| 缩略图 | 设计模板工具 | 一个模板复用 |

> 具体产品按预算与习惯自选，本手册不绑定特定工具。

## 更新节奏

- 起步：每周 1 期（质量优先）。
- 补充：每条长视频配 1–2 条 Shorts。
- 稳定后：可提到每周 1–2 期，并尝试系列专题。

## 质量自查清单（发布前）

- [ ] 钩子是否在 15 秒内抓住人？
- [ ] 所有关键数字 / 事实是否有公开来源？
- [ ] 死因鉴定是否有原创分析，而非复述？
- [ ] 措辞是否客观、无人身攻击式定性？
- [ ] 字幕是否全程、无错别字？
- [ ] 标题与缩略图是否匹配内容（不做标题党）？
- [ ] 是否加了"不构成投资建议"声明？
