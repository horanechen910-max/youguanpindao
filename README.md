# 败局档案馆 · 频道运营手册

> 一个不露脸、AI 辅助的中文商业纪录短片频道。用"法医解剖"的视角复盘中外公司、品牌、产品的兴衰，每期提供可迁移的商业认知增量。

## 频道一句话定位

不做成功学，专做"失败复盘 + 客观分析"。卖的不是猎奇，是"看完能学到东西"的确定性。
